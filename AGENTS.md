# DearDish

DearDish helps people facing health challenges adapt restaurant-style meals to their needs. It uses SvelteKit 2, Svelte 5, TypeScript, PostgreSQL with Drizzle ORM and postgres.js, and the Vercel AI SDK with OpenRouter. The app is configured for `@sveltejs/adapter-vercel` on `nodejs24.x`.

## Commands

- Install and run locally: `bun install`, `bun run dev`
- Build: `bun run build`
- Check and test: `bun run typecheck`, `bun run lint`, `bun run test`
- Database: `bun run db:generate`, `bun run db:migrate`, `bun run db:seed`

See [`docs/agent-docs/workflows.md`](docs/agent-docs/workflows.md) for script details, environment setup, and deployment caveats. Use commands declared in `package.json`; older README instructions may differ.

## Architecture Map

- `src/routes/` contains public and authenticated pages, form actions, and JSON endpoints.
- `src/lib/server/` contains authentication, database access, profile and meal operations, and AI adaptation.
- `src/lib/schemas.ts` defines shared input validation schemas.
- `src/lib/server/db/schema.ts` defines the database tables; `drizzle/` contains migrations.
- `scripts/seed.ts` seeds the dish catalog.

## Conventions

- Use Svelte 5 runes and snippets. Keep server-only logic under `src/lib/server/`.
- Validate inputs with `src/lib/schemas.ts`; form actions return field errors and submitted values on validation failure.
- Scope profile and meal operations to the authenticated user's id. Page authentication uses `locals.user` from `src/hooks.server.ts`.
- Colocate `*.test.ts` files with source. Route tests must not start with `+`; mock external database/auth dependencies where needed.
- Keep styles in plain CSS. Use the existing palette and typography tokens in `src/app.css`.
- Keep comments minimal and avoid em dashes in code and documentation.

## Env Vars

The app reads `PGHOST`, `PGUSER`, `PGDATABASE`, `PGPASSWORD`, `AI_API_KEY`, and `AI_MODEL`. Set them in the local environment or deployment settings; never commit `.env`. See [`docs/agent-docs/workflows.md`](docs/agent-docs/workflows.md) for current setup notes.
